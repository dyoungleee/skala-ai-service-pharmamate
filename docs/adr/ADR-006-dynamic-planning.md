# ADR-006: 복합 검색에 별도 Dynamic Planner를 추가하지 않음

- 상태: 보류
- 날짜: 2026-10-20

## 배경

LangGraph 라우터는 `memory_web` 경로에서 과거 학습 기록과 최신 검색을 모두 요청한다. 두 작업은 현재 순차 노드로 실행된다. 추가 Planner가 작업 완수율을 높일 수 있는지 검토했다.

## 검토한 대안

1. 현행 라우터가 복합 경로를 고르고 그래프의 두 검색 노드가 실행
2. 라우터 뒤에 LLM Planner를 두어 검색 작업을 별도 분해
3. Planner를 도입하고 의존성이 없는 작업만 병렬 처리

## 결정

현재는 1번을 유지한다. 복합 검색 12개에서 기준선과 Planner 모두 필요한 memory/web 작업을 12/12 선택했으며 Planner의 품질 이득이 없었다. 후보는 p50 지연을 1,101 ms에서 2,036 ms로 높이고 호출을 두 배, 토큰을 약 46% 증가시켰다.

## 결과와 제약

불필요한 두 번째 모델 호출을 피한다. 이 결과는 합성 복합 질문 12개의 작업 선택 결과이며, retrieval·답변 완수 품질은 직접 비교하지 않았다. 세부 조건은 [F8.2 실험 보고서](../experiments/F8_2_dynamic_planning.md)에 기록했다. 검색 흐름이 실제로 복잡해져 의존성 순서나 조건부 재계획이 필요해지면 새 평가셋으로 다시 검토한다.

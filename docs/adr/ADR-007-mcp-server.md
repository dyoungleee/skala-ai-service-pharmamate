# ADR-007: 읽기 전용 stdio MCP 서버 제공

- 상태: 채택
- 날짜: 2026-10-20

## 배경

PharmaMate의 학습 기록과 읽은 기사 검색을 외부 MCP 호스트에서 재사용할 방법이 필요하다. 앱은 익명 세션별 bearer 토큰을 발급하고, SQLite에는 토큰 해시만 저장한다.

## 검토한 대안

1. 현재 Python 함수에만 의존
2. 공식 MCP Python SDK의 stdio 서버로 Tool, Resource, Prompt 공개
3. 즉시 HTTP MCP 서버와 별도 OAuth 발급 서버까지 구축

## 결정

2번을 채택한다. 로컬 호스트가 stdio 프로세스를 실행하며, `PHARMAMATE_SESSION_TOKEN`을 시작 시 해시와 비교해 세션 ID를 확인한다. 프로세스는 하나의 세션에 고정되고, 함수는 세션 ID/토큰을 모델이 제어하는 도구 인수로 받지 않는다. 외부에서 내용을 바꾸는 쓰기 Tool은 제공하지 않는다.

## 근거

동일한 검색 함수를 합성 DB에서 직접 실행했을 때 p50은 0.317 ms, MCP stdio 호출은 1.010 ms였고 30/30회 성공 및 결과 일치를 확인했다. Tool 2개, Resource 1개, Prompt 1개가 등록되며, 별도 프로세스 테스트에서 세션 범위 격리를 확인했다. 세부 측정은 [F8.3 보고서](../experiments/F8_3_mcp_server.md)에 기록했다.

## 결과와 제약

MCP를 지원하는 로컬 호스트에서 기존 검색을 표준 인터페이스로 재사용할 수 있다. 작은 로컬 fixture의 0.693 ms p50 오버헤드는 허용 가능한 범위로 판단했다. 실제 네트워크 transport, 타 호스트, 대용량 기록 성능은 미측정이며, 세션 변경 시 서버 프로세스를 재시작해야 한다.

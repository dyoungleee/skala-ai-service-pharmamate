# ADR-005: 라우팅 프롬프트의 경로 우선순위 명시

- 상태: 채택
- 날짜: 2026-10-20

## 배경

기존 LangGraph `agent_router`는 기사, 개인 학습 기록, 최신 웹 검색, 복합 검색 중 하나를 고르는 LLM 노드다. 경로 설명은 있었지만, 최신성 질문과 개인 기록 요청이 함께 있을 때의 우선순위는 명시적이지 않았다.

## 검토한 대안

1. 기존 프롬프트 유지
2. 경로 정의와 선택 우선순위를 명시한 집중형 프롬프트 적용
3. 별도 경로 분류 노드나 두 번째 LLM 호출 추가

## 결정

2번을 채택한다. 추가 노드나 모델 호출 없이 `backend/app/agents/graph.py`의 라우터 지침을 구체화했다. 복합 최신성+기록 요청은 `memory_web`, 최신 사실만 필요하면 `web`, 과거 기록을 명시한 경우 `memory`, 나머지는 `article`로 선택하도록 했다.

## 근거

같은 `gpt-4o-mini`, temperature 0, 합성 질문 24개 비교에서 경로 정확도는 23/24에서 24/24로, p50 지연은 1,152 ms에서 1,046 ms로 변했다. 총 토큰은 20,765에서 20,859로 소폭 늘었다. 상세 조건과 결과는 [F8.1 실험 보고서](../experiments/F8_1_query_routing.md)에 있다.

## 결과와 제약

기본 개념 질문을 개인 기록 검색으로 보내는 실수를 줄였다. 입력 유형별 6개, 한 번씩 실행한 합성 평가만으로 실제 분포의 성능을 보장할 수 없다. 실제 사용자 데이터 없이 더 큰 평가셋으로 재검증해야 한다.

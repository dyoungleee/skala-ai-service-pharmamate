# ADR-004: 답변 근거 Validator와 제한된 재작성

- 상태: 채택
- 결정일: 2026-10-20
- 관련 기능: F3 Answer Validator

## Context

PharmaMate는 기사와 학습 기록을 바탕으로 제약·바이오 내용을 설명한다. 생성 모델이 임상시험의 평가 목적을 실제 결과처럼 표현하거나, 출처에 없는 수치·날짜를 덧붙일 수 있다. 이러한 구체 주장을 확인하는 답변 단계가 필요하다.

## Alternatives

1. 답변 생성 프롬프트만으로 근거 사용을 요청한다.
2. 별도 구조화 LLM Validator를 두고 불일치 시 무제한 재생성한다.
3. 구조화 LLM Validator와 명시적 수치·날짜/결과 미보고 보호 규칙을 두고, 재작성은 한 번으로 제한한다.

## Decision

옵션 3을 채택한다. Validator는 질문, 생성 답변, 기사·학습 기록·웹 문맥과 출처 메타데이터를 받아 `pass`, `revise`, `insufficient_evidence` 중 하나를 구조화해 반환한다. 수치·날짜가 근거 텍스트에 없거나, 결과 미보고 자료를 실제 임상 결과로 표현한 경우에는 결정적 규칙이 `pass`를 `revise`로 바꾼다. 수정 지침을 넣어 한 번만 답변을 다시 생성한다. 두 번째 검증도 실패하면 보수적인 근거 부족 문구를 반환한다. Validator 호출이 실패한 경우에도 검증되지 않은 답변을 확정하지 않는다.

## Consequences

- 근거가 부족한 구체 주장을 제거하거나 명시적으로 미확인 처리한다.
- 답변당 Validator 모델 호출이 추가되어 비용과 지연이 늘어난다. 문제를 찾아 한 번 재작성하면 답변·검증 호출이 더해진다.
- 같은 설정 모델을 재사용해 별도 서비스 운영을 피하지만, LLM 판단은 완전한 사실 보증이 아니다.
- 결정적 수치·날짜 검사는 표현이 다른 동등한 근거를 보수적으로 차단할 수 있다. 작은 합성 사례 결과는 실제 의학 정보 전반의 정확도 보증으로 해석하지 않는다.

## Evidence

합성 답변 12건에서 기대한 안전/위험 판정 일치율은 1.000(12/12), 근거 없는 답변 통과율 0/6, 근거 있는 답변 차단율 0/6이었다. 단일 Validator 호출 지연은 p50 0.993초, p95 1.205초였다. `EVIDENCE-01` 실제 모델 비교에서 한 번의 수정 후 임상 평가 목적과 미보고 결과를 구분했고, 후보 응답은 6.70초, 기준선은 2.91초였다. 조건과 한계는 [F3 실험 보고서](../experiments/F3_answer_validation.md)에 기록했다.

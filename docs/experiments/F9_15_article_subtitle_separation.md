# F9.15 기사 부제목 분리 및 분석 문맥 반영

## 변경 사항

- 기사 제목은 기존 제목 메타데이터와 `h1`에서 가져옵니다. 부제목은 `subtitle`, `subheadline`, `deck`, `article-summary` 등 명시적인 부제목 표식 또는 제목 바로 옆의 `h2`에서만 추출합니다.
- 추출된 제목과 부제목 노드는 본문 추출 전에 분리합니다. 본문에 부제목과 같은 문구가 다시 나오더라도 본문 문단은 그대로 보존합니다.
- 표시가 없는 첫 본문 문단은 리드문으로 유지합니다. 부제목이 확인되지 않으면 빈 문자열을 반환합니다.
- 이미지 캡션은 부제목 후보에서 제외하고 기존 본문 추출 단계에서도 제거합니다.
- 분석 API는 `title`, `subtitle`, `body`를 별도 필드로 반환합니다. 제목과 부제목은 주제 파악용 보조 문맥으로 전달하고, 요약·분석은 본문을 주 근거로 삼도록 프롬프트를 갱신했습니다.
- 기사 화면에는 부제목이 있을 때만 제목 아래에 표시합니다.

## 검증

- 추출 테스트에서 제목·부제목·본문 분리, 본문에 반복된 부제목 문구 보존, 제목에 붙은 `h2`, 실제 첫 문단 보존, 이미지 캡션 제외를 확인했습니다.
- API 테스트에서 응답 필드와 분석 프롬프트로 전달되는 제목·부제목·본문을 확인했습니다.
- 백엔드 전체 테스트: 65개 통과.
- Vue 프로덕션 빌드 통과.

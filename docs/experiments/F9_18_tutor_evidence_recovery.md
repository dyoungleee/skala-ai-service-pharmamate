# F9.18 AI Tutor 근거 보강 및 부분 답변 보존

## 변경 배경

기사가 `BSC·SoC`를 언급하더라도 특정 시험에서 어떤 약물·돌봄을 실제로 제공했는지는 별도 시험 자료가 필요하다. 기존 라우터는 최신성만 주로 검색 대상으로 보았고, 검증 실패 후 같은 자료로 답을 다시 작성했다. 두 번째 검증이 실패하면 확인된 일반 설명까지 통째로 근거 부족 문구로 바뀌었다.

## 처리 흐름

1. 라우터가 질문을 일반 개념, 기사 사실, 특정 시험 세부사항으로 분류하고 기사에서 빠진 근거를 기록한다. 기사 원문도 라우터에 제공한다.
2. `BSC·SoC`의 기본 정의는 NCI 사전의 출처가 붙은 참고 자료로 제공한다. 특정 시험의 구성·효과에 이 정의를 그대로 대입하지 않는다.
3. 특정 시험의 세부사항이나 최신 사실은 Tavily에서 공식 기관·임상시험 등록 사이트만 검색한다. 일반 정의만 묻는 경우에는 유료 검색을 호출하지 않는다.
4. 검증기는 답변의 개별 주장을 점검하고 확인된 내용은 `supported_answer`에 보존한다. 기사에 없는 수치·날짜·임상 결과는 기존의 결정적 검사로 한 번 더 막는다.
5. 핵심 근거가 부족하면 새로운 검색어로 최대 한 번 근거를 보강한 뒤 답변을 다시 작성한다. 검색어가 같거나 검색을 사용할 수 없으면 확인된 부분 답변을 우선 표시한다.

## 실제 질문에서 확인할 점

`BSC·SoC의 구체적인 구성 요소는 무엇이며, 각 요소가 환자에게 미치는 영향은 어떤가요?`를 기사와 함께 질문할 때 일반 정의와 시험별 확정 사실을 분리하는지, 특정 시험 자료를 찾지 못하면 그 구성·효과를 추측하지 않는지 확인한다. 답변에 제시된 출처가 실제 주장과 연결되는지도 확인한다.

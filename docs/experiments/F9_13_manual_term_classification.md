# F9.13 직접 추가 용어 분류

## 변경 사항

- 기사 원문에서 사용자가 직접 추가한 용어는 별도 분류 API로 보냅니다. 각 범주의 정의와 인접 범주 구분을 프롬프트에 명시하고, 기사 원문 근거와 확신도를 받아 검증합니다.
- 근거가 약하면 용어 표현에 적용되는 문맥 규칙으로 보조 분류하고, 분명한 기준이 없으면 Other로 분류합니다.
- 분류 API가 없거나 응답하지 않아도 용어를 화면 목록에 추가합니다. 프런트엔드는 선택 문구에 분명히 드러난 지표·임상 단계·허가·사업·생산·진단·바이오마커·기전 표현만 보조 분류에 사용합니다.
- 서버 저장에 실패해도 현재 화면에서 용어가 사라지지 않도록 처리합니다.
- 기사 문맥은 모델 문장으로 덮어쓰지 않고 원문 발췌를 저장합니다. 선택 용어가 긴 문단 뒤쪽에 있어도 주변 문맥이 포함되도록 용어 위치 중심으로 발췌합니다.

## 검증

- `PYTHONDONTWRITEBYTECODE=1 pharma/bin/python -m unittest discover -s backend/tests -v`: 백엔드 전체 61개 테스트 통과.
- `npm run build -- --configLoader runner --outDir /tmp/pharmamate-manual-term-build`: Vue 프로덕션 빌드 통과.
- `python -m compileall -q backend`: Python 문법 컴파일 통과.
- API 테스트에서 직접 추가한 용어의 범주·정의·원문 문맥이 반환되는지 확인합니다.
- 낮은 확신도의 분류가 규칙 기반 범주로 보정되고, 문맥에 없는 근거가 제시되면 정의를 지어내지 않는지 확인합니다.

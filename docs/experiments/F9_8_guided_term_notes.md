# F9.8 단계형 용어 설명과 편집 가능한 학습 메모

## 변경

- AI Tutor에서 용어를 선택하면 LLM 호출 전에 `한 줄 정의`, `쉽게 말하면`, `이 기사에서는`, `지금 기억할 한 가지`를 용어 카드에 즉시 표시합니다. 간단한 설명은 용어 분류와 기사 분석 결과를 사용합니다.
- 기본 안내 아래에서 AI Tutor에 추가 질문을 보내며 LLM과 학습할 수 있습니다.
- `대화를 반영한 학습 메모 만들기` 버튼은 현재 용어와 관련 있다고 판정된 최근 Q&A 최대 8개를 사용해 `한 줄 개념`, `헷갈렸던 부분 Q&A`, `기사에서 중요한 이유`, `기억할 점` 형식의 초안을 만듭니다. 질문이 없는 경우에도 Q&A가 비어 있는 기본 초안을 만듭니다.
- 초안은 textarea에서 자유롭게 수정할 수 있습니다. `이 용어 학습 기록 저장`은 편집한 메모 본문을 그대로 저장하고, 연관 Q&A는 복습 데이터로 함께 연결합니다.
- 이전 클라이언트 호환을 위해 메모 내용 없이 저장 요청을 보내면 백엔드에서도 같은 네 항목 형식으로 기본 메모를 만듭니다.

## 검증

- 백엔드 전체 테스트: 46개 통과. 자동 기본 메모 형식과 요청에 전달된 사용자의 편집 메모 원문 저장을 확인했습니다.
- 프런트엔드 `npm run build`: 성공. 현재 작업 전부터 남아 있던 `style.css`의 URL 문자열 때문에 CSS minifier 경고가 있었지만 번들은 정상 생성됐습니다.

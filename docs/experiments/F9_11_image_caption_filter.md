# F9.11 기사 이미지 캡션 제외

## 요구사항

이미지 캡션은 기사 본문과 관련이 있어도 원문 추출과 AI 분석 결과에서 제외한다. 캡션 제거를 위해 실제 기사 본문 문장과 문단을 삭제하지 않는다.

## 적용

- HTML 1차 처리: `figcaption` 및 캡션·이미지 설명을 나타내는 클래스, ID, `itemprop`, 접근성 라벨 요소만 제거한다. 문장 내용만 보고 문단을 삭제하지 않는다.
- LLM 2차 처리: 이미지 캡션과 설명문을 주제와 관련이 있더라도 요약, 업계 이슈, 용어 등의 분석 근거와 결과에서 제외하도록 지시한다. 실제 기사 본문 문장은 이미지 설명으로 오인해 제외하지 않도록 지시한다.

## 검증

`pharma/bin/python -m unittest discover -s backend/tests` 실행 결과: 48개 테스트 통과. 캡션 요소 제거와 실제 본문 문단의 문장·순서 보존을 확인했다.

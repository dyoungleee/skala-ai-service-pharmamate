# F9.14 넓은 화면 학습 레이아웃

## 변경 사항

- 공통 화면 최대 폭을 1,840px로 넓혀 큰 화면의 좌우 공간을 활용한다.
- 기사 읽기 화면은 입력 영역 아래에 2열 작업 공간을 둔다. 왼쪽에는 내부 스크롤이 있는 원문, 오른쪽에는 기사 유형·요약·업계 이슈·핵심 용어와 기사 저장을 표시한다.
- AI Tutor 화면은 왼쪽에 용어 선택과 Quick Study, 오른쪽에 질문·답변 대화창을 둔다. Your Memory 메모 편집 영역은 기존 흐름처럼 대화창 아래에 둔다.
- 학습 기록 화면은 좌우 2열을 넓혀 Study Memory와 Reading History를 나란히 보여준다. Study Memory는 용어 분류별 접기/펼치기 목록으로 바꿨고, Reading History의 이슈 및 최근 기사 목록은 유지했다.
- 820px 이하에서는 세 화면을 한 열로 전환하고, 기사 원문·채팅 스크롤 높이를 화면에 맞게 줄인다.

## 검증

- npm run build --prefix frontend: Vue 프로덕션 빌드 통과.
- 변경한 Vue 템플릿이 컴파일되는지 확인했다.
- 브라우저 미리보기 연결을 사용할 수 없어 캡처 기반 시각 검증은 수행하지 않았다.

## 한계

넓은 화면에서는 좌우 패널을 각각 스크롤하고, 좁은 화면에서는 콘텐츠를 세로로 읽는다. 실제 화면에서 확인한 후 여백, 패널 높이, 좁은 화면 전환 폭을 추가 조정할 수 있다.

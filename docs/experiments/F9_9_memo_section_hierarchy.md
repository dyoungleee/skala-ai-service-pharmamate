# F9.9 학습 메모 제목 가독성 개선

## 목적

`한 줄 개념`, `헷갈렸던 부분 Q&A`, `기사에서 중요한 이유`, `기억할 점` 제목을 설명보다 크게 보여 메모를 빠르게 훑을 수 있게 한다. AI Tutor의 빠른 용어 정리에서도 항목 제목과 설명의 시각적 위계를 분명히 한다.

## 변경 사항

- 한 덩어리 textarea를 네 개의 편집 가능한 설명란으로 분리했다.
- 메모 제목은 14px, 입력 설명은 12px로 표시한다.
- 학습 기록 상세 화면은 제목 12px, 설명 10px로 표시한다.
- 빠른 용어 정리 제목은 12px, 설명은 11px로 표시한다.
- 저장 데이터는 기존 제목과 설명의 줄바꿈 텍스트 형식을 유지해 기존 API와 기록을 이어 쓴다. 이전에 저장된 메모도 제목별로 나눠 편집 화면과 학습 기록에 표시한다.

## 확인 방법

1. AI Tutor에서 용어를 선택하고 `대화를 반영한 학습 메모 만들기`를 누른다.
2. 네 메모 항목 제목이 설명 글자보다 크게 보이는지 확인한다.
3. 설명을 수정하고 저장한 뒤 `내 학습 기록`에서 제목과 설명의 크기 차이 및 저장 내용을 확인한다.
4. 이전에 저장해 둔 메모가 있다면 해당 용어를 열어 항목별로 표시되는지 확인한다.

## 예상 결과

메모의 제목이 먼저 눈에 들어오고, 각 설명을 항목별로 편집하거나 다시 읽기 쉬워진다. 저장된 메모 형식은 기존 API와 호환된다.

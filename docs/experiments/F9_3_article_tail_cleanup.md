# F9.3 기사 본문 뒤 페이지 요소 제거

## 문제

기사 본문 영역 안에 `관련태그`, 기자 정보, `기자채널`, `다른기사`, 저작권 문구가 일반 텍스트로 함께 들어오는 경우가 있었습니다. 기존 추출기는 댓글·추천 기사 등의 HTML 요소는 제거했지만, 의미 없는 클래스나 태그가 없는 텍스트는 본문으로 남겼습니다.

## 변경

- 본문 텍스트를 줄 단위로 정리한 뒤 `관련태그`, `기자채널`, `다른기사`, `추천기사`, 이메일 또는 저작권 문구가 처음 나타나는 지점에서 이후 내용을 잘라냅니다.
- 사용자가 제공한 Newsway 화면의 본문 끝과 태그·기자·추천 기사·저작권 꼬리 내용을 재현한 회귀 테스트를 추가했습니다.
- 기사 컨테이너 선택 및 페이지 전체 텍스트를 본문으로 오인하지 않는 기존 테스트도 함께 통과했습니다.

## 검증

실행 명령:

```bash
PYTHONDONTWRITEBYTECODE=1 ./pharma/bin/python -m unittest backend.tests.test_article_extraction -v
```

결과: 본문 추출 테스트 3개 통과. Newsway 실제 URL은 제공되지 않아 네트워크를 통한 해당 기사 실페이지 검증은 하지 않았습니다. 실제 페이지에서 꼬리 제목이 본문과 같은 줄에 붙는 형식이 확인되면 해당 표기 변형을 추가해야 합니다.

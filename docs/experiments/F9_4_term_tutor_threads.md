# F9.4 용어별 AI Tutor 대화와 학습 기록 개선

## 요청 사항과 변경

- AI Tutor에 기사 핵심 용어와 저장된 용어를 고르는 선택기를 추가했습니다. 용어마다 대화 내용이 분리되며, 세션을 다시 열어도 각 용어 대화를 복원합니다. 서버가 과거 Q&A를 넣을 때도 현재 용어 키에 해당하는 기록만 전달합니다.
- 비어 있는 용어 대화에는 고정 시작 질문 3개를 표시합니다: 쉽게 비유하기, 기사에서 중요한 이유, 비슷한 개념과 비교. 이 버튼은 질문 입력란을 채웁니다. 답변 뒤의 후속 질문은 해당 용어의 최근 질문·답변을 참고해 생성하며, 누르면 바로 전송합니다. 추천 생성에 실패해도 직전 질문과 답변에 맞춘 기본 후속 질문을 제공합니다.
- 질문 입력란에서 Enter는 전송, Shift+Enter는 줄바꿈으로 동작합니다. 한글 IME 조합 중 Enter는 전송하지 않도록 처리합니다.
- 기전·메커니즘 질문은 원인과 결과가 이어지는 3~6단계로 설명하고, 기사에서 확인되지 않은 안정적인 기초과학 기전은 일반 배경지식이라고 구분하도록 Agent와 답변 검증 지침을 보강했습니다.

## 용어 학습 기록 저장 방식

- 답변은 대화 세션의 Q&A 기록에 자동 저장됩니다.
- `학습 기록 저장`을 누르면 선택 용어의 정의·분류·별칭과 사용자가 입력한 메모를 현재 세션의 SQLite 기록에 저장하거나 갱신합니다.
- 해당 용어에 연결된 것으로 판정된 질문·답변만 용어 학습 Q&A로 별도 연결합니다. 중복 저장은 방지합니다.
- 이 용어 기록은 같은 세션의 AI Tutor가 검색할 수 있는 학습 기억이 되고, 기사 원문에서는 복습 용어 표시 기준으로 사용됩니다. 빈 메모를 자동 요약으로 채우지는 않습니다.

## 검증

- 백엔드 전체 테스트: 42개 통과. 용어를 바꿔 질문한 뒤 같은 용어로 돌아왔을 때 다른 용어 대화가 이전 문맥에 섞이지 않는지 확인했습니다.
- 프런트엔드 `npm run build`: 성공.
- 실제 LLM의 답변 품질은 사용 중인 모델과 기사 문맥에 따라 달라질 수 있으므로, 기전 질문 예시를 실제 서비스 모델에 넣어 비교하는 평가는 별도로 남아 있습니다.

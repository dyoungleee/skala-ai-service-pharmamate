# F9.1 단계별 학습 화면과 원문 용어 하이라이트

## 변경 목적

기사 읽기, AI Tutor, 내 학습 기록을 한 화면의 여러 카드로 두던 UI를 학습 순서에 맞는 단계형 화면으로 정리한다. 원문에서 핵심 용어와 기존 학습 용어를 구분하고, 읽은 기사 저장 흐름을 이해하기 쉽게 안내한다.

## 구현 내용

- 화면 상단에 `기사 읽기 → AI Tutor → 내 학습 기록` 단계 내비게이션을 추가했다. 각 단계 사이에 이전/다음 이동 버튼을 두고, Vue 상태를 유지한 채 화면만 전환한다.
- 기사 분석이 끝나면 접히지 않은 전체 원문을 먼저 표시하고, 그 아래에 기사 유형·한 줄 정리·업계 이슈 브리핑을 표시한다.
- 기사 분석 결과의 핵심 용어와 별칭을 원문에서 찾아 긴 표현부터 강조한다. 저장 기록과 키 또는 별칭이 일치하지 않는 용어는 노란색 `#fde68a`, 현재 세션에 저장된 용어는 초록색 `#bbf7d0`으로 표시한다.
- 세션 학습 기록 API가 기존 용어 별칭도 반환하도록 확장했다. 기록이 저장되면 목록을 다시 불러오므로 해당 용어의 원문 표시가 즉시 복습 색상으로 바뀐다.
- `읽은 기사로 저장` 도움말에 자동 이슈 연결 기준을 설명한다. 현재 세션 안의 기존 이슈와 엔티티, 사건 유형, 임상 단계 및 이슈 문구를 비교하며, 적합한 이슈가 없으면 새 이슈를 만든다. 기존 이슈를 직접 지정하는 기능도 유지한다.
- URL 본문 추출에서 기사 영역에 포함될 수 있는 메뉴·공유·관련 기사·광고 영역을 추가로 제외한다. 기사 영역 선택자와 JSON-LD를 찾지 못하면 페이지 전체 텍스트를 본문으로 사용하지 않고 직접 붙여넣기를 요청한다.

## 용어 학습 판정 범위

현재는 활성 세션의 Vue 학습 기록만 복습 용어 판정에 사용한다. 기록에 쌓인 `term_key`, 용어명, 저장 별칭 중 하나가 기사에서 분석한 용어·별칭과 일치하면 복습 용어로 표시한다. 저장 용어가 늘어날수록 새 기사에서 같은 용어가 자동으로 복습 색상으로 표시된다.

기존 Notebook/Gradio 기록은 현재 Vue 세션에 자동으로 가져오지 않는다. 따라서 이 단계에서는 과거 Gradio 기록을 복습 판정에 포함하지 않는다.

## 검증

- `PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s backend/tests -v`: 39개 테스트 통과.
- `npm run build --prefix frontend`: Vue 프로덕션 빌드 통과.
- 기사 추출 테스트에서 대상 본문을 유지하고 관련 기사·공유 문구·메뉴 문구를 제외하는지 확인했다.
- 기사 영역 선택자가 없는 페이지에서는 일반 페이지 문장을 기사 본문으로 반환하지 않는지 확인했다.

## 한계

뉴스 사이트마다 기사 HTML 구조가 다르고 일부 사이트는 브라우저에서 실행되는 JavaScript로 본문을 생성한다. 선택자 기반 추출과 JSON-LD만으로 모든 사이트의 본문을 완벽히 구분할 수 없으므로, 기사 본문을 찾지 못하거나 결과가 맞지 않으면 직접 붙여넣기를 사용한다. 실제 사이트별 정확도 개선은 오류가 확인된 URL을 익명화한 HTML fixture로 추가 검증해야 한다.

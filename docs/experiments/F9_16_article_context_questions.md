# F9.16 일반 질문 모드의 기사 맥락 추천 질문

## 목표

AI Tutor에서 `일반 질문`을 선택했을 때 용어 학습용 고정 질문 3개 대신 현재 기사 전체 흐름을 살펴볼 수 있는 질문 2개를 제공한다. 선택 용어가 있거나 기사가 없을 때는 기존 용어 학습용 질문 3개를 유지한다.

## 구현

- Vue에서 기사와 일반 질문 모드가 함께 선택됐는지 확인해 추천 질문 표시 경로를 정한다(Query Routing).
- 기사 분석의 기존 구조화 LLM 호출에 `article_questions` 필드를 추가해 질문 2개를 함께 생성한다. 별도 LLM 왕복을 추가하지 않는다.
- 질문은 사건의 의미, 본문에 나온 기업·기술·용어의 관계, 업계 영향을 서로 다른 관점으로 묻도록 구성한다. 용어 정의만 되풀이하지 않으며 본문에서 확인되는 구체적인 단서를 포함한다.
- 후처리 Validator가 질문 개수, 길이, 물음표, 중복 여부와 본문 단서 포함 여부를 검사한다. 통과하지 못하면 본문에서 확인된 기업명·용어를 사용해 질문 2개를 만들고, 단서가 없으면 기사 분석 결과에 기반한 일반적인 기사 맥락 질문을 제공한다.
- 질문은 기사 분석 응답과 세션의 활성 기사 데이터에 저장된다. 용어 선택을 바꾸거나 세션을 다시 열 때 질문 생성을 반복하지 않는다. 같은 기사를 다시 분석하면 기존 기사 분석 요청은 다시 실행된다.
- 추천 버튼은 기존 동작을 사용해 질문 입력창에 질문을 채운다.

## 확인 결과

| 확인 항목 | 결과 |
|---|---|
| LLM 출력 요청 | 기사 맥락 기반 질문 2개를 구조화 응답에 추가 |
| 후처리 | 본문에 없는 기관·승인·임상 사실을 질문의 전제로 사용하지 않도록 본문 단서 검사 |
| 일반 질문 화면 | 기사+일반 질문에서는 2개, 용어 선택 또는 기사 부재 시 기존 3개 |
| 세션 복원 | 저장된 기사 분석 결과의 추천 질문을 세션 조회 응답에 포함 |
| 자동 테스트 | backend 전체 테스트 68개 통과 |
| 프론트엔드 빌드 | Vite production build 통과 |

## 실험 범위와 한계

이번 검증은 가짜 LLM 응답을 사용하는 자동 테스트와 프론트엔드 빌드로 수행했다. 실제 모델을 호출한 질문 품질·응답 시간·토큰 비용 비교는 실행하지 않았다. 생성은 별도 LLM 호출을 추가하지 않지만, 기사 분석 응답에 질문 2개가 포함되어 완료 토큰이 늘 수 있다. 질문이 본문 단서를 포함하는지는 코드로 확인하지만, 질문의 의미적 다양성과 유용성은 실제 기사 평가셋으로 추가 검토해야 한다.

# F9.5 이미지 출처 및 저작권 문구 정리

## 문제

기사 본문 컨테이너 안에 `사진=뉴스웨이`, `이미지 출처: ...`, `Photo: ...` 같은 이미지 크레딧이나 저작권 표시가 일반 텍스트로 포함되면 원문에 그대로 노출될 수 있었습니다. 직접 붙여넣는 본문은 URL 추출과 다른 경로를 사용해 기존 후처리가 적용되지 않았습니다.

## 변경

- URL에서 추출한 본문과 직접 붙여넣은 본문 모두 동일한 줄 정리 후처리를 적용합니다.
- 사진·이미지 출처/제공/저작권, 자료 사진, Photo/Image credit 및 단독 저작권 표시 줄을 제거합니다.
- 이미지 크레딧이나 저작권 문구가 본문 문장 끝에 같은 줄로 붙으면 해당 표기부터 잘라 앞의 문장은 보존합니다.
- 이미지 크레딧 및 저작권 표기를 포함하는 URL HTML과 직접 입력 회귀 테스트를 추가했습니다.

## 검증

```bash
PYTHONDONTWRITEBYTECODE=1 ./pharma/bin/python -m unittest discover -s backend/tests -v
```

결과: 전체 백엔드 테스트 44개 통과. 실제 뉴스 기사 URL은 이번 검증 fixture에 포함되지 않았으며, 표기 변형이 추가로 확인되면 정규식과 회귀 테스트를 보강할 수 있습니다.

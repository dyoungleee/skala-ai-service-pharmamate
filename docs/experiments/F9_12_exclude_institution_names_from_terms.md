# F9.12 기관명을 학습 용어에서 제외

## 변경 사항

- 정부부처, 규제기관·의약품청, 병원, 대학, 연구기관 등의 기관 이름·약칭·현지어 정식 명칭을 핵심 학습 용어에서 제외하도록 분석 프롬프트를 보강했다.
- 모델이 기관을 용어로 반환해도 기관명 표지와 `key_entities`에 든 기관명 별칭을 기준으로 결과를 후처리한다. 기관은 기사 주요 엔티티에 남긴다.
- 임상 단계, 허가 절차, 의약품 후보, 표적, 작용 기전과 같은 일반 개념은 유지한다.

## 검증

브라질 보건부 산하 의약품청의 한글 명칭·ANVISA 약칭·포르투갈어 정식 명칭은 제거되고, `의약품 품목 허가`와 `임상 3상`은 유지되는 테스트를 추가했다.

`pharma/bin/python -m unittest discover -s backend/tests` 실행 결과: 50개 테스트 통과.
